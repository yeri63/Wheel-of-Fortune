<p>Play the TV game Wheel of Fortune on a Cisco IP Phone. All the puzzles are song titles from popular films and musical groups my daughters enjoy and typically sing afterwards when they're in the mood. To help come up with the title and what letters to guess, a hint with the film name is shown when the game starts.</p>
