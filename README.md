# Wheel of Fortune
<div align="center">
  
![Screenshot of Wheel of Fortune](https://github.com/yeri63/Wheel-of-Fortune/blob/master/wheel.png)
</div>
Play the TV game Wheel of Fortune on a Cisco IP Phone. All the puzzles are song titles from popular Disney and Dreamworks films my daughters enjoyed and typically sang afterwards when they were young. To help come up with the title and what letters to guess, a hint with the film name is shown when the game starts.
